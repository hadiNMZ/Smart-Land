# Smart Land - Corporate Static Website

A multimedia-rich static website built for **Smart Land**, a global technology solutions and consultancy firm founded in 2011. Developed as part of the Multimedia Systems course curriculum (ITE_BMM601 / ISE_MM) at Syrian Virtual University (SVU).

## 📌 Project Overview
The website showcases Smart Land's profile, core services, and featured projects, integrating web-optimized media formats and accessible user experience:
* **Company Profile:** Corporate identity, vision, and service domains.
* **Portfolio Showcase:** Flagship products including Smart Signal, MyKey, Sada, and Welcome.
* **Optimized Media:** High-resolution digital imagery delivered strictly in `.webp` / `.avif` formats for fast performance.


## 🛠 Tech Stack
* **HTML5:** Semantic document structure and media elements (`<video>`, `<track>`, `<picture>`).
* **CSS3:** Responsive layout, modern color palette, and component styling.
* **JavaScript (ES6):** Client-side interactivity and navigation behavior.
