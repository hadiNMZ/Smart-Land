# Smart Land - Corporate Static Website

A multimedia-rich static website built for **Smart Land**, a global technology solutions and consultancy firm founded in 2011[cite: 1]. Developed as part of the Multimedia Systems course curriculum (ITE_BMM601 / ISE_MM) at Syrian Virtual University (SVU)[cite: 1].

## 📌 Project Overview
The website showcases Smart Land's profile, core services, and featured projects[cite: 1], integrating web-optimized media formats and accessible user experience[cite: 1]:
* **Company Profile:** Corporate identity, vision, and service domains[cite: 1].
* **Portfolio Showcase:** Flagship products including Smart Signal, MyKey, Sada, and Welcome[cite: 1].
* **Optimized Media:** High-resolution digital imagery delivered strictly in `.webp` / `.avif` formats for fast performance[cite: 1].
* **Interactive Video:** Promotional video with synchronized captioning (`.vtt`) and background audio[cite: 1].
* **AI Integration:** AI-assisted content and asset generation[cite: 1].

## 🛠 Tech Stack
* **HTML5:** Semantic document structure and media elements (`<video>`, `<track>`, `<picture>`)[cite: 1].
* **CSS3:** Responsive layout, modern color palette, and component styling[cite: 1].
* **JavaScript (ES6):** Client-side interactivity and navigation behavior.
